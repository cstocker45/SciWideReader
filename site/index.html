<WideReader>

Hides the sidebars on journal websites so the paper itself (text and figures) gets the full width of your browser. Adjustable font, text size and line spacing.

Features

works without per-site rules

Finds the block of the page with the most paragraph text, hides whatever sits beside it and widens the column. Headers, footers and figures stay.

typography

Font (Serif, Book, Sans, Wide), text size, line spacing, paragraph spacing and maximum text width. Changes apply live.

per-site switch

On by default for ~30 journal sites (Nature, Cell, Science, PNAS, PMC, bioRxiv, eLife…). Turn it on anywhere else with Alt+W.

private

No data collection, no network requests, no accounts. Settings stay in your browser. Privacy policy.

Install

  1. Chrome Web Store: click Add to Chrome above (when listed).
  2. Manually: download WideReader.zip and unzip it.
  3. Open chrome://extensions, switch on Developer mode, click Load unpacked and pick the unzipped folder.
